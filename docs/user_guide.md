# User Guide

## Data Format

Excel file must contain:
- `drainI` — drain current (A)
- `drainV` — drain-source voltage (V)
- `gateI` — gate leakage current (A)
- `gateV` — gate-source voltage (V)

## Analysis Steps

1. Upload Excel file
2. Select Forward or Reverse sweep
3. Choose metric to extract
4. Download results
