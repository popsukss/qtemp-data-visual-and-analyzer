# QTEMP FET Data Analyzer

A Streamlit-based dual-sweep FET analyzer for extracting key device metrics.

## Features

- Dual-Sweep Support
- Subthreshold Swing (SS) Extraction
- Transconductance (gm) Extraction
- Mobility Calculation
- Ion/Ioff Ratio Analysis
- Interactive Plotting
- Results Export (CSV/Excel)

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
streamlit run src/fet_analyzer/app.py
```
